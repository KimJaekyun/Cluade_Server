# 1945 SKY STRIKER (Pygame)

세로 스크롤 슈팅게임. 외부 이미지/사운드 파일 없이 코드로 그리고 합성합니다.

## 실행
```
pip install pygame
python main.py
```

## 조작
| 키 | 동작 |
|---|---|
| 방향키 / WASD | 이동 (Shift: 정밀 이동, 피격 판정 점 표시) |
| Space / J / Z | 발사 (누르고 있으면 연사) |
| B / X / Ctrl | 폭탄 (탄 제거 + 광역 피해) |
| P | 일시정지 |
| Esc | 타이틀로 / 종료 |

## 아이템
- **P** 파워업 (최대 4단계, 초과 시 1000점) / **B** 폭탄 / **UP** 목숨 / **$** 500점

## 구성
- 스테이지 3개, 각 스테이지 끝에 3단계 패턴 보스
- 스테이지 웨이브는 `stages.py`에서 수정, 적 종류는 `enemies.py`의 `TYPES`
- 하이스코어는 `highscore.txt`에 저장
